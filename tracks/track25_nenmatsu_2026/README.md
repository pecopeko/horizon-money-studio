# NENMATSUGATE (`nenmatsu-2026-csv-auditor`)

**令和8年分（2026年分）年末調整 178万・136万・197万円の壁 ＆ 特定親族特別控除 一括CSV検算・手取りシミュレータ**

- **Live Zero-Backend Web App (`connect-src 'none'`, 100% ブラウザ内完結・外部送信ゼロ)**: https://pecopeko.github.io/nenmatsu-2026-csv-auditor/
- **Statutory Basis**: 国税庁 (`nta.go.jp`) タックスアンサー No.1410 / No.1411 / No.1199 / No.1180 / No.1177 / No.1191 / No.1195 / No.2260、『令和8年4月 源泉所得税の改正のあらまし』、『令和8年度税制改正Q&A（令和8年5月）』（令和8年12月1日施行）

## 主な検算・シミュレーション機能

1. **令和8年分（2026年分）vs 令和7年分（2025年分）法定テーブル完全対応**
   - **給与所得控除**: 最低保障額 `74万円`（収入 `219万1,000円〜220万円未満` の措法29条の4第3項調整テーブルおよび `660万円未満` の所得税法別表第五・4,000円単位端数処理に1円単位で完全準拠）
   - **基礎控除**: 合計所得 `489万円以下` 一律 `104万円`（給与のみ最大 `665万5,556円以下`）、`489万超〜655万円以下` `67万円`、`655万超〜2,350万円以下` `62万円`
   - **扶養控除・配偶者控除**: 合計所得要件 `62万円以下`（給与収入 `136万円以下`）、配偶者特別控除上限 `133万円以下`（給与収入 `207万円以下`）
   - **特定親族特別控除（19歳以上23歳未満）**: 合計所得 `62万円超〜123万円以下`（給与収入 `136万円超〜197万円以下`）の **9段階控除テーブル（63万→61万→51万→41万→31万→21万→11万→6万→3万円）**
2. **経理・労務向け CSV 一括検算（UTF-8 BOM / Shift-JIS `cp932` 自動判定・Excel出力）**
   - 大学生年代の子（136万〜197万円）の特定親族特別控除の申告漏れ、旧令和7年基準（123万円/58万円の壁）の誤適用、基礎控除の旧区分残存、令和8年11月30日以前退職者の施行日前トラップ（Q1-3）、ひとり親控除38万円フライング計上（Q3-2）を自動検出。

## CLI Usage

```bash
# サンプルCSV（8名分・全トラップ網羅）で一括検算＆Excel用BOM付CSV出力
python3 -m tracks.track25_nenmatsu_2026.cli --sample-csv --export-csv audit_report.csv

# 世帯別の令和8年 vs 令和7年シミュレーション
python3 -m tracks.track25_nenmatsu_2026.cli --simulate --salary 6200000 --spouse-salary 1500000 --child-age 20 --child-salary 1520000
```
