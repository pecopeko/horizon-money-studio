## Engine A — 12-Point Revenue & AI-Search Readiness Diagnostic (`b2b_teardown_generator.py`)

Strictly **SSRF-safe** (blocks private/loopback/link-local/metadata IPs, non-80/443 ports, and unsafe redirects), read-only, zero paid API keys:

1. **AI-Search / GEO Readiness (25 pts)**:
   - `/llms.txt` machine-readable Markdown manifest presence, H1 & link structure
   - `/robots.txt` explicit AI crawler directives (`GPTBot`, `ClaudeBot`, `PerplexityBot`, `OAI-SearchBot`)
   - XML `/sitemap.xml` validity, `<loc>` count, and `/robots.txt` declaration
2. **Structured Revenue & Rich-Snippet Data (25 pts)**:
   - `application/ld+json` Schema.org parsing (`Organization`, `Product`, `Offer`, `FAQPage`, `WebSite`, `@graph`)
   - OpenGraph (`og:title`, `og:description`, `og:image`, `twitter:card`) completeness
   - Single absolute HTTPS `<link rel="canonical">` hygiene
3. **Trust, Security & Deliverability Posture (25 pts)**:
   - HTTPS enforcement + `Strict-Transport-Security` (`max-age`)
   - Core browser headers (`Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`/`frame-ancestors`, `Referrer-Policy`)
   - Public DNS TXT lookup via Cloudflare DoH (`cloudflare-dns.com/dns-query`) for **SPF (`v=spf1`)** and **DMARC (`_dmarc.<apex>`)** enforcement
4. **Conversion, Mobile & Regional Compliance (25 pts)**:
   - `<title>` and `<meta name="description">` length & SERP hygiene
   - `<img>` `alt` attribute coverage and exact missing count
   - Mobile `<meta name="viewport">`, HTML byte weight, plus automatic **Japan EC/B2B detection** (`特定商取引法` & `プライバシーポリシー` visibility when Japanese content is detected)

### Quickstart (Run on Any Public Domain)

```bash
pip install httpx
python b2b_teardown_generator.py scan https://example.com \
  --out-dir docs \
  --pitch-dir outreach_samples \
  --templates-dir n8n_templates
```

Outputs per scanned domain:
- `docs/teardown_<domain>.html` — self-contained, XSS-safe interactive diagnostic scorecard with tailored copy-paste fixes
- `outreach_samples/pitch_<domain>_en.md` & `pitch_<domain>_jp.md` — evidence-only EN & JP outreach drafts
