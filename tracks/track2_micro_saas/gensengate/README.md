# GENSENGATE（源泉門）

**日本の源泉徴収税（10.21%／20.42%）・手取り逆算（グロスアップ）・2026年10月インボイス経過措置50%負担・支払調書集計 ブラウザ完結台帳**

- 公開URL（GitHub Pages）: `https://pecopeko.github.io/gensengate/`
- オフライン・ゼロ外部通信（100% クライアントサイド ESM）

## 主な機能
1. **報酬・料金の源泉徴収税自動計算（所得税法第204条・復興特別所得税2.1%）**: `100万円以下 10.21%`／`100万円超 20.42%（102,100円加算）` および司法書士等 `1万円控除` に対応。
2. **国税庁タックスアンサー No.6929 税込/税抜誤計算ガード**: 請求書に本体価格と消費税の明確区分がない場合、税込総額が源泉対象となる点と過剰源泉額（円）を即座に警告します。
3. **2026年10月 インボイス経過措置50%（80%→50%減額）実質負担試算 + Mod-9 T番号検算**: 適格請求書T番号が未登録・チェックデジット誤りの場合、発注側の仕入税額控除不可コスト増を可視化します。
4. **手取り額からのグロスアップ逆算 ＆ 『支払調書』（年5万円超）UTF-8 BOM CSV集計**: 支払先ごとに合算し、法定提出対象フラグ付きでExcel文字化けしないCSVを生成します。
