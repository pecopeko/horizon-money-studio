# ANPOGATE（安保門）

**経済安全保障推進法（特定社会基盤役務15業種・特定重要設備事前届出・特定重要物資供給網分散・特許出願非公開）＆ 重要経済安保情報保護・活用法（セキュリティ・クリアランス 2025年5月施行・適性評価・適合事業者保全施設）ブラウザ完結ローカル監査ツール**

- 設備導入計画・維持管理委託先・取扱担当者適性評価状況・特定重要物資の依存国比率を外部サーバーへ **一切送信しません**（ネットワーク通信 `0` 回）。
- 基幹インフラ事前届出義務・未クリアランス者アクセス違反・単一国 `>=50%` 依存集中リスクを即時検出し、**『経済安全保障・セキュリティクリアランス 事前届出・保全管理計画書（Markdown）』** を生成します。
