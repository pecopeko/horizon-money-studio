# DENCHOGATE（電帳門）

**100%ブラウザローカル完結・取引先や請求データの外部送信ゼロ**で、改正電子帳簿保存法（第7条電子取引）に必要な「取引年月日・取引先名・取引金額」の標準ファイル名（`YYYYMMDD_取引先名_金額.pdf`）一括生成（和暦・全角数字対応）、適格請求書T番号 Mod-9 妥当性チェック、国税庁モデル準拠の検索用索引簿 CSV 出力、運用フロー自己点検、及び「電子取引データの訂正及び削除の防止に関する事務処理規程」Markdown 生成を行う静的Webツールです。
