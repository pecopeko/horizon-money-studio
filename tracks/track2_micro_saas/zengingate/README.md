# ZENGINGATE v2.0（全銀門）

100% ブラウザローカル完結・外部通信ゼロの **銀行提出用 Shift-JIS (CP932) 全銀120バイト振込データ変換・銀行エラー1クリック自動修復・適格請求書T番号 Mod-9 ワークベンチ**。

- ライブWebアプリ: https://pecopeko.github.io/zengingate/
- ゼロ外部依存・ゼロCDN（社内閉域網 / オフラインPCでもそのまま動作）

## v2.0 主な機能
- **真の Shift-JIS (CP932) バイナリ出力 (`encodeZenginShiftJis`)**: 半角カナ (`U+FF61–U+FF9F` → `0xA1–0xDF`) と ASCII を厳密1バイト変換し、`Uint8Array` で各レコード厳密120バイト（CRLF/改行なし・EOF `0x1A` 選択可）を出力
- **7銀行プリセット & 振込種別対応**: 全銀標準 / 三菱UFJ (BizSTATION) / 三井住友 (Web21) / みずほ (e-ビジネス) / 楽天銀行 / 住信SBIネット銀行 / GMOあおぞらネット銀行、種別コード `21` 総合振込・`11` 給与振込・`12` 賞与振込、Pos 112 振込指定区分 (`7`/`8`)・Pos 113 識別表示 (`Y` 自動付与)
- **公式法人略語（前後中ルール・25種超）& 濁点保護30バイト切捨**: 前株 `ｶ)〇〇`・後株 `〇〇(ｶ`・中株 `〇〇(ｶ)△△` ほか 25 種超の法人格略語に対応し、30バイト境界で濁点・半濁点が分離しない安全切捨を実装。漢字は絶対に無言削除せず赤枠で即時警告
- **会計CSV/TSV自動取込 (`parseTransferCsv`)**: RFC-4180 引用符 (`"¥125,000"`)・Excel先頭0欠落補完 (`5` → `0005`)・freee / MoneyForward / 弥生 / Excel ヘッダ自動マッピング
- **銀行エラーファイル 1クリック自動修復 (`diagnoseAndRepairZenginFile`)**: UTF-8誤保存・BOM・全角スペース・桁ズレ・トレーラ件数/合計不一致・エンド欠落を診断＆修復
- **適格請求書T番号 / 法人番号 Mod-9 一括検証 & 印刷用「振込承認チェックシート」**
