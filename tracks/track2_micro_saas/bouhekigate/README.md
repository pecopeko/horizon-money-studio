# BOUHEKIGATE（防壁門）

**経産省（METI）2026 サプライチェーン強化に向けたセキュリティ対策評価制度（★3・★4）・個人情報保護委員会（PPC）漏えい速報(3〜5日)/確報(30/60日)・不正競争防止法（営業秘密3要件）・SPF / DMARC ブラウザ完結ローカル診断ツール**

- 外部サーバー・LLM・SaaSへ機密情報や取引先チェックシート内容を **一切送信しません**（ネットワーク通信 `0` 回）。
- 社内体制の自由記述と SPF / DMARC DNS レコードを入力するだけで、8つの統制領域を自動判定し、**『取引先提出用 情報セキュリティ対策状況回答書（Markdown）』** を即時生成します。

## テスト実行

```bash
node --test tracks/track2_micro_saas/bouhekigate/test/bouheki-engine.test.mjs
```
