## 商品説明文（BOOTH / Gumroad コピペ用）

取引先情報・マイナンバー・請求書・未公開LP原稿を外部クラウドへ1バイトも送らず、自社PC・閉域網ブラウザ内だけで処理できる業務スイート（HTMLツール3種＋Chrome拡張機能2種＋一括バッチPython CLI＋監査証跡証明書テンプレート）です。

### 同梱ツール一覧
1. **KUROGATE（黒門）**: 国税庁Mod-9法人/適格請求書T番号（`T+13桁`）・マイナンバーMod-11検証＋リバーシブル伏せ字＋プロンプトインジェクション事前遮断
2. **YAKKIGATE（薬影）**: LP・EC・PR投稿の **薬機法・景品表示法（根拠記載なきNo.1/二重価格）・ステマ規制** スパン強調＋適法リライト案出力
3. **ZENGINGATE（全銀門）**: 適格請求書T番号の一括Mod-9検算＋ひらがな/全角カナ/小書き文字/濁点1バイト分解の **全銀半角カナ自動補正**＋**120バイト総合振込データ生成・検算**
4. **オフライン一括処理 CLI (`batch_compliance_suite_cli.py`)**: 社内CSVをコマンド1行で全項目監査し、**SHA-256改ざん検知ハッシュ付き監査報告書** を出力

### 動作環境・ライセンス
- WebUI/拡張機能: Google Chrome / Microsoft Edge / Firefox（インターネット切断状態でも動作）
- CLI: Python 3.11+（外部有料APIキー一切不要）
- 配布ZIPファイル: `japan-b2b-compliance-pro-suite-v1.0.0.zip`（GitHub Release `v1.0.0-pro-kit` に生成済み）
